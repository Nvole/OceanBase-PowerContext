# Qoder 赛题：科研资料检索助手

状态：代码、本机验收和 Qoder Sites 公开发布已完成；平台提测仍待提交。
准备日期：2026-10-27（北京时间）。

## 赛题要求

来源：本地已抓取的《赛题汇总与完整正文.md》Qoder 章节，题面关联文档更新时间 2026-10-26。
题目：用 Qoder 做一个让学习、科研和工作更高效的项目，20 分。

- 主要开发工作必须在 Qoder 中完成，桌面端、IDE、JetBrains 插件或 CLI 均可；只用 Qoder 发布网站不符合要求。
- 必须实际使用 seekdb、PowerContext 中的至少一种，不能仅安装或测试连接。
- 项目网站必须通过 Qoder Sites 发布，且未登录也能访问。
- 基于 oceanbase/powercontext 的 2026-competition-ecosystem 分支开发，项目资产已放在 qoder/ 目录。
- 提交网站网址、代码仓库、运行说明、验证样例、真实的 Qoder 开发记录及账号 UID。
- 私有报名仓库保持私有；评审访问权限按赛题平台配置，不得直接公开报名仓库。

## 选题与最小版本

问题：论文阅读笔记、实验记录和组会待办分散，难以按关键词、资料类型和标签找到对应出处。
项目：科研资料检索助手。首次版本导入 Markdown/TXT，保存原文、标题、类型、标签、段落及出处；检索后返回匹配段落并打开原文。支持新增、检索、详情和删除。
指定技术：使用 seekdb 实际存储和检索。PowerContext、向量检索及模型问答不是首次版本的前置条件；没有实现的能力不在网站中宣称。
建议技术：Python + FastAPI + MySQL 协议驱动 + 简洁网页。具体驱动和依赖版本在 Qoder 中实测后固定，不能把建议当作已验证兼容性。

## 实现边界

- 独立项目数据库建议名 qoder_research，禁止修改已通过部署验收的 competition_practice 数据库或其他科研目录。
- 数据库连接通过环境变量配置；示例仅占位，不读取、提交或展示本机凭据文件。
- 可使用 seekdb 全文检索；先核实部署版本、中文分词及相关语法。如果首次版本采用参数化 LIKE 查询，应明确标为关键词检索，不宣称向量或混合检索。
- 筛选和匹配必须由 seekdb 实际执行，不能把全部数据读到 Python 后伪装成数据库检索。
- 仅接受 UTF-8 Markdown/TXT，限制单文件大小；保留标题、来源文件名和稳定文档 ID，避免同名文件覆盖。
- 所有 SQL 参数化，正文按文本展示，禁止直接执行资料中的脚本或指令。
- Qoder Sites 发布公开展示网站，含项目简介、真实截图、代码获取方式和本地复现步骤。题面允许项目网站作为展示入口；不要假设它能直接访问本机 127.0.0.1 数据库。
- 真实用户数据、提效比例和访问统计仅在真实测量后填写。

## 开发顺序与产物

1. Qoder 读取任务书，核实仓库分支、环境与数据库连接，记录发现。
2. Qoder 实现 schema、数据导入、关键词检索、类型/标签筛选和删除接口，保留开发对话。
3. Qoder 实现网页主要流程，接入真实接口；准备示例数据和自动化验证。
4. 运行样例并保存不含密码的数据库查询结果、接口结果和测试日志。
5. 整理 README、.env.example、依赖文件、验证步骤与真实截图。
6. 在 Qoder 中通过 Qoder Sites 发布网站，设置公开访问；记录站点链接和账号 UID。
7. 确认无痕访问、评审可复现、提交材料齐全后，按平台入口提交。

验收方案见《验收样例.md》，启动提示词见《粘贴给Qoder的任务.md》。
