📚 科研资料检索助手

基于 seekdb 的科研文档检索系统 — OceanBase 2026 竞赛作品

项目简介

论文阅读笔记、实验记录和组会待办分散在多个文件中，难以按关键词、资料类型和标签快速找到对应出处。本项目提供一个统一的文档管理和检索系统，支持导入 Markdown/TXT 文件，按关键词搜索并返回匹配段落和原文出处。

核心功能

📤 上传资料

支持 .md / .txt，自动解析标题、类型、标签和段落

🔍 关键词检索

在标题、正文和标签中搜索，返回匹配段落

🏷️ 类型/标签筛选

按 reading/experiment/todo 类型和自定义标签过滤

🗑️ 管理操作

查看详情、删除文档，同名文件不覆盖

技术架构

后端 Python 3.13 + FastAPI
数据库 seekdb (MySQL协议)
ORM SQLAlchemy 2.1.6
驱动 PyMySQL 1.2.3
前端 原生 HTML/CSS/JS
开发工具 Qoder IDE

本地复现

1. 安装依赖

pip install -r requirements.txt

2. 选择数据库

SQLite 可直接启动。真实 seekdb 使用显式连接 JSON（自备 host/port/user/password，勿提交凭据）或进程环境变量；项目不自动读取 .env。

3. 导入样例 & 启动

python scripts/run.py --sqlite --import-examples # 或连接自备 seekdb（固定独立数据库 qoder_research） python scripts/run.py --connection-file .local/connection.json --import-examples

托管边界：本网站是公开静态作品展示，不是在线 FastAPI 业务服务；数据库与业务 API 须按说明本地独立运行。

4. 运行测试

# 隔离测试（不影响实际数据库） python -m pytest tests -q -p no:cacheprovider
