# 组会材料检索方案

使用者是要准备组会的人。输入是一条中文材料，或一个关键词加一句语义查询。输出是带代号和原文的材料，而不是模型改写的段落。

## 数据

集合名固定为 `track05_labnotes`，库是 `track05_qoder`。每条材料的文档正文包含代号、标题、主题、场合和正文，全文条件才能碰到代号。元数据只重复这些可显示字段。

种子不少于 10 条，内容是自拟组会笔记。新导入材料由服务生成 `LN` 加 10 位十六进制的代号，不加连字符，避免全文查询把代号拆开。

向量是 64 维、余弦距离的字符二元片段哈希。`embedding_function` 设为 `None`，调用 knn 时只传 `query_embeddings`。这样不会加载默认的 MiniLM，也不会下载模型。哈希向量只证明近邻链路可用，不代表语义质量。

## 检索

每次检索都调用：

```text
hybrid_search(
  query.where_document.$contains = 关键词,
  knn.query_embeddings = 本地向量,
  rank.rrf = {},
)
```

返回后再用关键词子串留下真正含有该词的材料。RRF 会把近邻结果并进来，那些不含关键词的近邻不显示为命中。独特代号能被找到，靠的是全文那一路把它带进混合结果，而不是页面另外补一条记录。

种子导入和新材料导入在 `upsert` 之后都调用 `refresh_index`，再允许检索。

## 入口

`labnotes.py` 是唯一的写入和检索实现。网页和测试都调用它。空关键词、过长文本和不含汉字的导入会在这里拒绝。

`server.py` 没有绑定参数。主机不是 `127.0.0.1` 或端口不是 `18605` 时直接拒绝启动。

## 不做的事

- 不覆盖 `.env`，不在日志、页面和结果文件里写口令。
- 不重启 seekdb，不写其他赛题目录，不删除 `track05_labnotes` 以外的集合。维度不一致时只重建这个集合。
- 不伪造 Qoder Sites 网址或截图。没有账号，状态记为 blocked。
